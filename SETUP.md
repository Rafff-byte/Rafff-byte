# Rafff-byte GitHub Profile Kit

## Included
- `README.md` — futuristic glass-inspired GitHub profile layout
- `assets/banner.svg` — custom blue/black profile banner
- `.github/workflows/snake.yml` — generates the animated contribution snake

## Install
1. Create a public repository named exactly `Rafff-byte` (same as your GitHub username).
2. Upload the contents of this kit to the root of that repository. Keep the `.github/workflows/snake.yml` path.
3. Commit the files to the `main` branch.
4. Open the repository's **Actions** tab and enable Actions if GitHub asks.
5. Run **Generate contribution snake** once with **Run workflow**. It will publish an `output` branch.
6. The contribution snake image should appear after the workflow succeeds. The README can take a short while to refresh.

## Personalize before publishing
- Replace `your.email@example.com` with your public contact email, or remove the email buttons.
- Replace `YOUR-LINKEDIN` with your LinkedIn username / URL.
- Replace the portfolio `#` placeholder with your published portfolio URL.
- Update the short project descriptions after reviewing each repository.
- The stats and activity cards are generated by third-party services and may occasionally be rate-limited or unavailable.

No password or personal access token is needed for these manual steps. GitHub Actions uses the repository's built-in `GITHUB_TOKEN`.
